# AI Agent Task Graph — граф задач для AI-агента

Промпт для разбиения сложных задач на граф небольших проверяемых шагов. Предусматривает параллельную работу, точечные исправления и продолжение выполнения между сессиями.

**Язык:** [English](README.md) · Русский

## Промпты

- [Русская версия](prompt.ru.md)
- [English version](prompt.en.md)

## Принцип работы

- **Планирование:** задача разбивается на узлы с входами, результатами, зависимостями и критериями приёмки.
- **Выполнение:** независимые узлы обрабатываются параллельно; детерминированные операции выполняются кодом.
- **Проверка:** результат принимается по наблюдаемым доказательствам; повторяются только неуспешные узлы.
- **Продолжение:** решения, проверки, результаты и незавершённые задачи сохраняются в Markdown-файлах.
- **Контроль:** соблюдаются разрешения, границы изменений, лимиты и обязательные согласования.

## Использование

1. Откройте промпт на нужном языке.
2. Заполните шесть параметров: `{{TASK}}`, `{{OUTPUT}}`, `{{CHECKS}}`, `{{SOURCES}}`, `{{SCOPE}}` и `{{LIMIT}}`.
3. Передайте его агенту с доступом к файлам, инструментам проверки и субагентам.
4. Проверьте и утвердите предложенный граф задач до начала выполнения.

В ходе работы создаются `graph.md` (граф задач), `checks.md` (результаты проверок), `progress.md` (состояние для продолжения) и `CLAUDE.md` (выработанные правила). Эти файлы — результаты выполнения, а не часть данного репозитория.
